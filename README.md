# Проект автоматизации тестирования API Stellar Burgers

## Описание
Проект содержит автоматизированные тесты для API сервиса Stellar Burgers. Тесты охватывают основной функционал работы с пользователями и заказами.

## Технологии
- Python 3.x
- Pytest
- Requests
- Allure Framework

## Реализованные тесты

### Пользователи
1. Создание пользователя:
   - Успешное создание уникального пользователя
   - Попытка создания дубликата пользователя
   - Создание пользователя без обязательных полей

2. Логин пользователя:
   - Успешная авторизация
   - Авторизация с неверными данными

3. Обновление данных пользователя:
   - Обновление с авторизацией
   - Обновление без авторизации

### Заказы
1. Создание заказа:
   - С авторизацией
   - Без авторизации
   - Без ингредиентов
   - С неверными ингредиентами

2. Получение заказов:
   - Получение списка заказов авторизованного пользователя
   - Попытка получения заказов без авторизации
   - Проверка с неверным токеном
   - Проверка с просроченным токеном
   - Проверка структуры заказа в ответе

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone <repository-url>
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Запустить тесты:
```bash
pytest
```

4. Сгенерировать Allure-отчет:
```bash
pytest --alluredir=test_results/
allure serve test_results/
```

## Особенности реализации
- Использование фикстур для подготовки тестовых данных
- Автоматическая очистка тестовых данных после выполнения тестов
- Подробное логирование с помощью Allure
- Параметризация тестов
- Проверка как позитивных, так и негативных сценариев

## Структура API клиента
API клиент (api_client.py) реализует следующие методы:
- Регистрация пользователя
- Авторизация
- Обновление данных пользователя
- Удаление пользователя
- Создание заказа
- Получение списка заказов
- Получение списка ингредиентов
- Работа с токенами
